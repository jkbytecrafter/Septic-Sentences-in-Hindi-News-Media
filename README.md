# Hindi-SEPSIS Balanced Dataset

## Overview

This repository contains a balanced dataset for **Hindi Septic and Pure sentence classification**.

## Dataset Statistics

- Total Sentences: **100**
- Septic: **50**
- Pure: **50**

## Dataset Columns

| Column | Description |
|---|---|
| Hindi News Sentences | Hindi news sentence |
| Label | Septic or Pure |
| Domain | News category |

## Domains

- Political
- Disputes
- Business
- Sports
- International Affairs
- Entertainment
- Technology

## File

`Balanced_Sepsis_Categorized.xlsx`

## Usage

The dataset can be used for:

- Hindi NLP
- Text Classification
- Machine Learning
- Bias Detection Research
